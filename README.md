# Oliv Branding Agency - HTML & CSS Clone

A pixel-perfect, fully responsive landing page replica of the Oliv Branding Agency template, built entirely from scratch using pure HTML5 and modern CSS3.

## 🎯 Project Overview
The goal of this project is to recreate a premium, high-fidelity web design without relying on JavaScript for layout or standard UI interactions. It serves as a practical demonstration of advanced frontend styling techniques, built as a showcase piece for my professional curriculum vitae and web development portfolio.

## 🛠️ What I am Doing with HTML & CSS

This project heavily utilizes modern CSS capabilities to handle complex layouts and animations that might typically rely on JavaScript. Here is a breakdown of my approach:

### 1. Semantic HTML Structuring
* **Logical Document Flow:** Using semantic HTML5 tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) to ensure the page is accessible, SEO-friendly, and easy to read.
* **Modular Containers:** Grouping elements logically to prepare them for CSS Grid and Flexbox manipulation, keeping the DOM structure as flat and clean as possible.

### 2. Advanced CSS Layouts
* **CSS Grid:** Implementing two-dimensional layouts for the "Services", "Selected Work", and "Blog" sections. Grid is used to perfectly match the column sizing, gaps, and responsive masonry-style arrangements of the original design.
* **Flexbox:** Utilizing Flexbox for one-dimensional alignments, such as centering items within cards, distributing space in the navigation bar, and aligning icons with text.
* **CSS Variables (Custom Properties):** Setting up a `:root` directory for the specific color palette (off-whites, dark greys, subtle purples) and typography settings to maintain consistency across the entire stylesheet.

### 3. CSS-Only Interactivity & Animation
* **Infinite Marquee:** Creating the continuously scrolling client logo section using purely CSS `@keyframes` and `transform: translateX()` to loop the content seamlessly.
* **Hover States & Transitions:** Using CSS `transition` properties to recreate the smooth, premium feel of hovering over portfolio cards, buttons, and navigation links.

### 4. Responsive Design
* **Media Queries:** Writing comprehensive `@media` breakpoints to ensure the layout gracefully degrades on smaller viewports. 
* **Fluid Typography & Spacing:** Adjusting padding, margins, and font sizes dynamically so the design looks perfect on mobile phones, tablets, and wide desktop monitors.
